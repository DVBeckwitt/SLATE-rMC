# Codex execution

The current user task, `../AGENTS.md`, `../WORKTREE_LAUNCH.md` and
[VALIDATION.md](VALIDATION.md) govern execution. Historical task prompts are records.

- Keep one implementation writer; use bounded read-only reviews when useful.
- Reuse existing physics and fitting owners. Do not create parallel orchestration.
- Inspect evidence before choosing a method. Historical visual agreement alone does not
  establish equal source laws, normalization, measurement operators or physical validity.
- Make the requested change, check its actual risks, review and integrate a coherent commit.
- Keep temporary diagnostics and experiment history external. No retained test suite or
  generic proof/benchmark campaign belongs in the repo or its default workflow.
- Preserve active work and report failures with the exact affected operation and evidence.
