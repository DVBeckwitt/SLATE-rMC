# Measured experiment history

Consult relevant measured attempts before substantial iterative work. Record useful outcomes,
failures and concrete repair explanations externally so later work does not repeat exhausted
approaches. History is evidence, not new authorization or a numerical acceptance rule.

The development tool is [tools/dream-rsi](../tools/dream-rsi/SKILL.md), separate from the numerical
package; its installed personal copy and records live outside this repository.

```powershell
python -B tools/dream-rsi/scripts/dream_rsi.py history --repo .
```

The former canned SLATE evaluator has been removed. There is no default test/proof campaign.
Direct cleanup and deterministic fixes use ordinary edits. When an authorized task genuinely
benefits from comparing competing approaches, define its finite scope and repeatable evaluator
in an external task configuration. Keep one writer, protect inputs and tolerances, and separate
software feasibility from physical adequacy. Never invent a scalar research score.

The generic bundled skill's examples do not authorize restoring pytest or proof runners here.
Follow [VALIDATION.md](VALIDATION.md); do not transplant the retired suite into external tooling.
Candidate adoption still requires normal review and integration, never automatic promotion.
